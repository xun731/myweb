簡易抽卡系統

Python 2025 大一上期末專題
GitHub

玩了這麼多年手遊，每次最期待的就是抽卡了！於是期末專題就決定自己來做一個，抽到爽為止！

從登入系統、抽卡機制、資料儲存，到小遊戲獲取金幣，整個系統從零開始設計。

功能介紹

帳號系統　輸入用戶名稱登入，第一次使用會自動建立帳號。每個帳號的資料都存在獨立的資料夾裡，切換帳號或登出都不會影響其他人的紀錄。也可以刪除帳號，但刪了就真的找不回來了。

抽卡　單抽或十連抽，每抽消耗一枚金幣。卡片分三種稀有度——R、SR、SSR，有保底機制，每 80 抽必出 SSR。

查詢抽卡紀錄　顯示總抽數、已獲得的 SSR 數量、距離下次保底還差幾抽，以及每一筆抽卡的詳細紀錄（時間、稀有度、卡片名稱）。

背包　查看目前擁有的所有卡片，依系列和編號排列，跳號就代表還沒抽到那張。

圖鑑　查看所有可以抽到的卡片清單，輸入系列名稱後顯示該系列完整內容。

小遊戲（金幣來源）

  • 數字炸彈：在範圍內猜出隱藏數字，用越少次猜中金幣越多
  • 猜拳：贏得 3 枚金幣，平手重來，輸了摸摸鼻子

計分系統　即時分數 + 當局最高分紀錄，右側全程顯示。

音效系統　每個頁面、每個動作都有對應的音效，吃蘋果、死亡、按按鈕各自不同。

結束畫面　可以選擇重新開始（保留最高分）或回首頁（重啟程式）。

已知問題

資料以明文儲存在本地，直接打開檔案就能修改金幣或抽卡紀錄，完全沒有防作弊機制。另外金幣的修改方法是公開的，理論上外部程式可以直接存取——這在單機版不是問題，但如果要變成連線遊戲就會是很大的漏洞。
